# QuQu 任务管理系统设计文档

## 概述

QuQu项目采用统一任务管理系统（Unified Task System）来解决AI任务阻塞和重复请求问题。该系统通过完整的任务生命周期管理、自动去重机制和严格的并发控制，确保语音识别、AI修正和翻译任务的稳定执行。

## 任务生命周期

### 状态流转

```
PENDING → RECOGNIZING → RECOGNIZED → CORRECTING → CORRECTED → TRANSLATING → COMPLETED
   ↓           ↓            ↓           ↓           ↓            ↓
 FAILED/ TIMEOUT  FAILED/ TIMEOUT  FAILED/ TIMEOUT  FAILED/ TIMEOUT  FAILED/ TIMEOUT
```

### 详细状态说明

| 状态 | 说明 | 超时时间 |
|------|------|----------|
| PENDING | 任务已创建，等待处理 | - |
| RECOGNIZING | 语音识别处理中 | 30秒 |
| RECOGNIZED | 语音识别完成 | - |
| CORRECTING | AI文本修正处理中 | 30秒 |
| CORRECTED | 文本修正完成 | - |
| TRANSLATING | 翻译处理中 | 30秒 |
| COMPLETED | 全部流程完成 | - |
| FAILED | 处理失败 | - |
| TIMEOUT | 处理超时 | - |

### 2. 自动去重机制

```python
# processing_texts集合防止相同文本重复处理
self.processing_texts: set = set()

# 修正去重
if task.recognized_text in self.processing_texts:
    logger.info(f"文本正在处理中，跳过修正: {task.recognized_text[:20]}...")
    return True

# 翻译去重
if source_text in self.processing_texts:
    logger.info(f"文本正在处理中，跳过翻译: {source_text[:20]}...")
    return True
```

### 3. 超时保护

每个处理阶段都有严格的30秒超时限制，防止任务无限等待：


### 任务提交流程

```python
def submit_task(self, audio_segment, record_id=None,
               enable_correction=True, enable_translation=True,
               priority=TaskPriority.NORMAL) -> str:
    # 1. 创建统一任务
    task = UnifiedTask(audio_segment=audio_segment, record_id=record_id)

    # 2. 添加到任务管理
    self.active_tasks[task.task_id] = task

    # 3. 提交到优先级队列
    priority_item = (task.priority.value, task.created_at, task.task_id)
    self.pending_tasks.put(priority_item)

    return task.task_id
```

## 回调机制

### 回调适配

```python
def _on_recognition_complete_adapter(self, unified_task: UnifiedTask):
    """识别完成回调适配器"""
    if self.on_recognition_complete:
        # 创建兼容的RecognitionTask对象
        recognition_task = RecognitionTask(
            audio_segment=unified_task.audio_segment,
            task_id=unified_task.task_id,
            record_id=unified_task.record_id
        )
        recognition_task.result = unified_task.recognition_result
        self.on_recognition_complete(recognition_task)
```

### 回调链

1. **识别完成** → `on_recognition_complete`
2. **修正完成** → `on_correction_complete`
3. **翻译完成** → `on_translation_complete`
4. **任务完成** → `on_task_complete`

## 错误处理与恢复

### 错误处理策略

```python
def _process_correction(self, task: UnifiedTask) -> bool:
    """处理AI修正 - 具备完善的错误处理"""
    try:
        # 执行修正逻辑
        result = future.result(timeout=task.correction_timeout)
        return True
    except TimeoutError:
        # 超时处理 - 使用原文继续
        task.corrected_text = task.recognized_text
        return True  # 继续后续流程
    except Exception as e:
        # 异常处理 - 使用原文继续
        task.corrected_text = task.recognized_text
        return True  # 继续后续流程
```

## 性能优化

### 1. 线程池优化

- **语音识别线程池**: 1个线程，避免音频处理冲突
- **AI处理线程池**: 1个线程，控制AI调用频率
- **工作线程**: 1个线程，协调任务流程

### 2. 内存管理

- **队列容量限制**: 最多100个待处理任务
- **活跃任务清理**: 任务完成后立即清理
- **去重集合管理**: 及时移除已处理的文本

### 3. 超时控制

- **识别超时**: 30秒
- **修正超时**: 30秒
- **翻译超时**: 30秒
