# 文档归档目录

本目录包含已完成、过时或历史性的项目文档，保留用于参考和追溯。

## 目录结构

### design/ - 设计方案归档
已完成实施的设计方案和规划文档

- `实时模式多线程优化方案.md` - 实时模式的多线程优化设计（已实施）

### fixes/ - 修复方案归档
已解决的问题修复方案和技术文档

- `FLET_THREAD_SAFETY_FIX.md` - Flet线程安全问题修复方案（已完成）

### changelogs/ - 变更日志归档
特定日期的变更日志快照

- `CHANGELOG-2025-10-05.md` - 2025年10月5日变更日志

### development/ - 开发记录归档
开发过程中的修复记录和调试日志

- `修复记录-2025-10-05.md` - 2025年10月5日修复记录
- `BUGFIX_LOG.md` - Bug修复日志（截至9月30日）

### reports/ - 报告归档
测试报告、验证报告和分析报告

- `验证报告-2025-10-05.md` - 2025年10月5日验证报告

---

## 归档原则

文档归档遵循以下原则：

1. **已完成的设计方案** - 设计已实施并稳定运行
2. **已解决的问题** - 修复方案已实施且问题不再复现
3. **特定时期快照** - 特定日期的记录，主要用于历史追溯
4. **过时的技术文档** - 因技术栈更新或重构而过时的文档

## 查阅指南

- 如需了解项目历史演进：查看 `changelogs/` 和 `development/`
- 如需参考旧的设计决策：查看 `design/`
- 如需了解已解决的问题：查看 `fixes/` 和 `development/`
- 如需查看历史测试结果：查看 `reports/`

## 活跃文档

当前活跃的项目文档位于：
- `/docs/` - 核心文档目录
- `/README.md` - 项目主文档
- `/CLAUDE.md` - AI开发配置
