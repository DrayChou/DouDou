# 翻译功能使用示例

本文档展示如何在QuQu语音助手中使用新增的翻译功能和自定义Prompt配置。

## 功能特性

1. **分层AI配置** - 支持默认配置和任务特定配置
2. **配置继承** - 翻译服务可复用AI修正配置，也可独立配置
3. **自定义Prompt** - 支持内联和文件两种Prompt存储方式
4. **多语言支持** - 支持10种目标语言翻译
5. **任务队列** - 独立的翻译任务队列，不阻塞识别流程

## 基础使用

### 1. 启用翻译功能

```python
from src.utils.config_manager import ConfigManager

# 创建配置管理器
config_manager = ConfigManager()

# 启用翻译功能
config_manager.set("enable_translation", True)
config_manager.save()
```

### 2. 配置翻译服务

#### 方式一：复用AI修正配置（推荐）
```python
# 翻译将使用AI修正的API设置
# 只需要配置目标语言
config_manager.set_ai_service_config("translation", {
    "target_language": "en",  # 英文
    # api_key, base_url, model_name 将自动从default继承
})
```

#### 方式二：独立配置
```python
# 为翻译服务配置独立的API
config_manager.set_ai_service_config("translation", {
    "api_key": "your_translation_api_key",
    "base_url": "https://api.openai.com/v1",
    "model_name": "gpt-4",
    "target_language": "ja",  # 日文
})
```

### 3. 提交翻译任务

```python
from src.core.task_manager import TaskManager, TranslationTask

# 创建任务管理器（传入配置管理器）
task_manager = TaskManager(config_manager=config_manager)
task_manager.start()

# 创建翻译任务
translation_task = TranslationTask(
    original_text="你好，这是一个测试文本",
    source_language="zh",
    target_language="en",
    priority=TaskPriority.NORMAL
)

# 提交翻译任务
future = task_manager.submit_translation_task(translation_task)

# 等待结果（可选）
result = future.result()
if result.get("success"):
    print(f"翻译结果: {result.get('result')}")
else:
    print(f"翻译失败: {result.get('error')}")

task_manager.stop()
```

## 高级配置

### 1. 自定义翻译Prompt

```python
# 保存自定义Prompt到配置
custom_prompt = """你是专业的技术文档翻译专家，专门翻译技术文档：

翻译规则：
1. 保持技术术语的准确性
2. 保留代码和格式不变
3. 适应目标语言的技术文档习惯
4. 保持原文档的结构层次

请翻译以下技术文档："""

config_manager.save_prompt("translation", custom_prompt)
```

### 2. 使用文件存储Prompt

```python
# 对于长Prompt，建议保存到文件
long_prompt = """... 很长的Prompt内容 ..."""

config_manager.save_prompt("translation", long_prompt, use_file=True)
# Prompt将保存到 prompts/translation.txt
```

### 3. 批量翻译配置

```python
# 支持多种目标语言配置
target_languages = ["en", "ja", "ko", "fr"]

for lang in target_languages:
    config_manager.set_ai_service_config(f"translation_{lang}", {
        "target_language": lang,
        "system_prompt": f"翻译成{config_manager.get_translation_language_name(lang)}："
    })
```

## 完整示例

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
翻译功能完整使用示例
"""

import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'src'))

from utils.config_manager import ConfigManager
from core.task_manager import TaskManager, TranslationTask, TaskPriority
from core.task_processors import TaskProcessorRegistry

def setup_translation_demo():
    """设置翻译演示"""
    print("=== 翻译功能演示 ===")

    # 1. 创建配置管理器
    config_manager = ConfigManager()

    # 2. 配置AI服务
    config_manager.set_ai_service_config("default", {
        "api_key": "your_api_key",
        "base_url": "http://localhost:11435/v1",
        "model_name": "qwen-turbo"
    })

    # 3. 启用翻译功能
    config_manager.set("enable_translation", True)

    # 4. 配置翻译服务（复用默认配置）
    config_manager.set_ai_service_config("translation", {
        "target_language": "en"
    })

    # 5. 自定义翻译Prompt
    custom_prompt = """你是专业翻译助手，请将以下中文文本翻译成英文：

要求：
1. 保持原意不变
2. 语法正确，表达自然
3. 符合英语表达习惯
4. 专业术语翻译准确

请直接返回翻译结果："""

    config_manager.save_prompt("translation", custom_prompt)

    print("✅ 配置完成")
    return config_manager

def demonstrate_translation(config_manager):
    """演示翻译功能"""
    print("\n=== 演示翻译功能 ===")

    # 创建任务管理器
    task_manager = TaskManager(config_manager=config_manager)
    task_manager.start()

    # 测试文本
    test_texts = [
        "你好，世界！",
        "这是一个语音识别系统。",
        "今天天气很好，适合出去散步。"
    ]

    for text in test_texts:
        print(f"\n原文: {text}")

        # 创建翻译任务
        translation_task = TranslationTask(
            original_text=text,
            source_language="zh",
            target_language="en"
        )

        # 提交任务
        future = task_manager.submit_translation_task(translation_task)

        # 等待结果
        try:
            result = future.result(timeout=30)
            if result.get("success"):
                print(f"译文: {result.get('result')}")
            else:
                print(f"翻译失败: {result.get('error')}")
        except Exception as e:
            print(f"任务超时或失败: {e}")

    # 显示统计信息
    stats = task_manager.get_statistics()
    print(f"\n统计信息:")
    print(f"  翻译任务完成: {stats.translation_completed}")
    print(f"  翻译任务失败: {stats.translation_failed}")
    print(f"  成功率: {stats.success_rate:.2%}")

    task_manager.stop()

if __name__ == "__main__":
    config_manager = setup_translation_demo()
    demonstrate_translation(config_manager)
```

## 注意事项

1. **API配置** - 确保AI服务的API Key和URL配置正确
2. **网络连接** - 翻译功能需要网络连接访问AI服务
3. **Prompt优化** - 根据具体需求优化Prompt可获得更好效果
4. **并发控制** - 默认翻译线程池大小为2，可根据需要调整
5. **错误处理** - 翻译失败会自动重试，建议添加适当的错误处理逻辑

## 故障排除

### 常见问题

1. **翻译功能未启用**
   - 检查配置中的 `enable_translation` 是否为 `True`

2. **API调用失败**
   - 验证API Key和URL是否正确
   - 检查网络连接和防火墙设置

3. **翻译结果不理想**
   - 优化自定义Prompt
   - 尝试不同的AI模型
   - 调整temperature参数

4. **性能问题**
   - 减少并发翻译任务数量
   - 优化网络连接
   - 考虑使用更快的AI模型
